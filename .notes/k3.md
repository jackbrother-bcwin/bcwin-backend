# 🎲 K3 Game Logic (Final Rules)

## 1. Purpose
K3 is a **dice-based lottery game** where **3 dice (1–6 each)** are rolled every period.  
- Players bet on **sums, triples, doubles, sequences, big/small, odd/even, etc.**  
- Winning is determined by the result of the dice roll.  
- Each bet type has a **multiplier payout**.  
- Service fee (e.g., 2%) applies before payout.  

---

## 2. Result Generation
- System rolls **3 dice** each round.  
- Calculate:  
  - **Sum** = d1 + d2 + d3 (range: 3–18).  
  - **is_triple** → TRUE if all 3 dice are same.  
  - **is_double** → TRUE if at least 2 dice are same.  
  - **is_all_different** → TRUE if all 3 dice are unique.  
  - **is_consecutive** → TRUE if numbers form a sequence (123, 234, 345, 456 in any order).  

---

## 3. Bet Types

- 🎯 **Sum Bets (3–18)** → Win if exact sum matches.  
- 🎲 **Triples**  
  - **Any Triple** → any of 111, 222, …, 666.  
  - **Specific Triple** → e.g., 333 only.  
- 🎲 **Doubles**  
  - **Any Double** → at least 2 dice are the same (but not triple).  
  - **Specific Double Combo** → e.g., (4,4,6).  
- 🔀 **All Different** → all dice unique.  
- 🔗 **Two Numbers** → both chosen numbers appear, order irrelevant.  
- 📏 **Consecutive Sequence** → dice form consecutive numbers (123/234/345/456).  
- 🔺 **Big / Small**  
  - Big = sum 11–18.  
  - Small = sum 3–10.  
- ⚖️ **Odd / Even Sum** → based on sum parity.

---

## 4. Payout Multipliers

💰 Assume **2% service fee** →  
`contract_amount = bet_amount – (bet_amount × 0.02)`  

| Bet Type             | Multiplier (×) |
|-----------------------|----------------|
| **Sum (3–18)**       | 1:6 – 1:50 (varies by probability) |
| **Triple (specific)**| 150× |
| **Triple (any)**     | 24× |
| **Double (specific)**| 8× |
| **Double (any)**     | 3× |
| **All Different**    | 6× |
| **Two Numbers**      | 5× |
| **Consecutive**      | 50× |
| **Big / Small**      | 1.95× |
| **Odd / Even**       | 1.95× |
| **Specific Combo**   | Configurable |  

---

## 5. Settlement Logic

1. Deduct service fee → `contract_amount`.  
2. Roll 3 dice → derive sum, triples, doubles, etc.  
3. For each bet:  
   - Match bet_type against result.  
   - Apply multiplier if win.  
   - Payout = `contract_amount × multiplier`.  
4. If no match → payout = 0.

## 7. Efficiency & Settlement Rules for AI

- Always calculate **contract_amount = bet_amount – fee**.  
- Resolve result properties first (sum, triple, double, sequence).  
- Map outcomes → then settle bets.  
- Atomic & idempotent settlement (no double payouts).  
- Multipliers applied strictly as per table.
