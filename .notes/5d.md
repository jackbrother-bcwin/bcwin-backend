# 🎲 5D Game Logic (Final Rules)

## 1. Overview
- Each round generates a **random 5-digit number (00000–99999)**.  
- Digits are labeled **A, B, C, D, E**.  
- Players can bet on **individual digits** (position-based) or the **sum** of all digits.  
- Settlement is based on configured multipliers.  

---

## 2. Bet Types

### A. Position Bets (A–E)
- **Exact Number (0–9)** → Win if digit matches.  
- **Low (0–4)** → Win if digit between 0–4.  
- **High (5–9)** → Win if digit between 5–9.  
- **Odd (1,3,5,7,9)** → Win if digit is odd.  
- **Even (0,2,4,6,8)** → Win if digit is even.  

---

### B. Sum Bets (0–45)
- **Exact Sum (0–45)** → Win if predicted sum matches A+B+C+D+E.  
- **Low (0–22)** → Win if sum ≤ 22.  
- **High (23–45)** → Win if sum ≥ 23.  
- **Odd** → Win if sum is odd.  
- **Even** → Win if sum is even.  

---

## 3. Payout Multipliers (Configurable)

| Bet Type               | Multiplier (×) |
|-------------------------|----------------|
| Position Exact Number   | 9×             |
| Position Low/High       | 1.95×          |
| Position Odd/Even       | 1.95×          |
| Sum Exact (0–45)        | 45×            |
| Sum Low/High            | 1.95×          |
| Sum Odd/Even            | 1.95×          |

---

## 4. Settlement Rules
1. Deduct bet amount upfront.  
2. Generate **5-digit result (A–E)**.  
3. Compute `SUM = A+B+C+D+E`.  
4. For each bet:
   - Map bet type → outcome check.  
   - Apply multiplier if win.  
   - If lose → 0 payout.  
5. Update balances atomically.  
6. Re-running settlement must not double-pay (idempotent).  

---

## 5. Example Scenarios (Edge Cases)

### Example 1 – Position Exact Match
- Draw: `12345` → A=1, B=2, C=3, D=4, E=5  
- Bet: **A=1, amount=₹100**  
- Win → 100 × 9 = ₹900  

---

### Example 2 – Position Low/High
- Draw: `56789` → A=5  
- Bet: **A=High (₹100)**  
- Win → 100 × 1.95 = ₹195  

---

### Example 3 – Position Odd/Even
- Draw: `24680` → B=4  
- Bet: **B=Even (₹200)**  
- Win → 200 × 1.95 = ₹390  

---

### Example 4 – Sum Exact
- Draw: `13579` → SUM = 25  
- Bet: **Sum=25, amount=₹100**  
- Win → 100 × 45 = ₹4500  

---

### Example 5 – Sum Low/High
- Draw: `98765` → SUM = 35 (High)  
- Bet: **Sum High (₹100)**  
- Win → 100 × 1.95 = ₹195  

---

### Example 6 – Sum Odd/Even
- Draw: `11111` → SUM = 5 (Odd)  
- Bet: **Sum Odd (₹100)**  
- Win → 100 × 1.95 = ₹195  

---

### Example 7 – Losing Bet
- Draw: `00000` → SUM = 0  
- Bet: **Sum High (₹100)**  
- Lose → payout = ₹0  

---

## 6. Efficiency Rules for AI
- Always precompute digit properties (low/high, odd/even).  
- Map `SUM` once, then apply all sum-related bets.  
- Multipliers must be configurable via admin.  
- Edge cases (e.g., SUM=0 or SUM=45) still follow rules.
